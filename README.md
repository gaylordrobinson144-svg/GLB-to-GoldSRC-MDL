This is a program made to convert GLB to MDL(GoldSRC) easily

How to install: 
-install the newest release
-put it where you want it to go to

How to use:

-Open the exe
-type the path to your glb file (example "C:\glbs\glbfile.glb")
-press enter

Remember:
-You have to open a new program window everytime you want to convert a glb file
-Your model must be within the GoldSRC limits
